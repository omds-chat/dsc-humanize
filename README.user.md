# dsc-humanize

## 这个插件做什么

插件想让 ds-chat 里的助手更接近你期望的样子。

它不承诺把助手变成某种固定形态:助手该是什么样子,由你在插件界面里输入与编辑。插件要做的是把人性化资产完整地交给你编辑:界面里能设置的属性覆盖资产的每一项;资产格式已由 dsc-humanize-asset-template 定稿,等编辑界面落地后,编辑结果可以一比一导出为标准 dsc-humanize-asset 资产包,也可以一比一导入这类资产包,到那时不存在你无法设置的属性。预设资产包只是起点,由 dsc-humanize-inner-asset 以可导入的资产包形式提供,并不代表插件只支持那几种样子。

## 目前状态

当前版本已有内核、宿主请求接线、资产市场标签与人性化开关,但上面说的编辑界面与导出仍未实现:没有可用的资产包时它不改动请求,只在插件日志里记录会话切换,并在首次激活时用一条气泡提示安装完成。资产包格式已由 dsc-humanize-asset-template 定义(格式版本 1.1.0),内核按类型读取资产包;导入目前有两条路——在资产市场标签里安装合集里的资产包,或由调用方以 JSON 文本调用导入接口,编辑与导出尚未落地。

## 安装

1. 打开聊天网页的插件面板。
2. 在「从地址安装」中粘贴插件地址,点击「安装」。
3. 安装成功后插件自动激活,状态显示为「运行中」;打开「查看日志」可以看到插件写入的内容。

本插件与 dsc-llm-tune 互斥:两者都改写请求参数,不能同时启用。已经装了其中一个时,再装另一个会被宿主拒绝;要换用请先卸载已装的那个。

## 使用

界面上目前有三个入口,全部由宿主按插件交的描述渲染,没有弹窗、没有遮罩:

| 入口 | 位置 | 作用 |
|:---:|:---:|:---:|
| 资产市场 | 会话视图的标签栏 | 浏览合集里的资产包并安装;来源开关与自建来源在这一页的表单里 |
| 人性化 | 输入框下方的工具条 | 一键开关「是否启用资产改写」,按钮上直接显示「开」或「关」;关闭时请求按原样发出,打开时按资产改写请求 |
| 资产状态通知 | 右上角的通知卡片 | 只在资产来源连不上或当前没有可用的资产包时出现,说明原因;问题解决后自动消失 |

切换会话时它会记录一条日志,可在插件面板的「查看日志」中查看。编辑界面与导出上线后,本节会说明入口与操作方式。

## 隐私与安全

本插件当前申请七项能力:订阅会话切换事件、弹出气泡提示、读写自己的插件存储(一次性迁移过渡快照,并存放人性化开关与安装记录)、在请求发出前读取最后一条用户消息并按资产给出补丁、经宿主的受控通道读取远端资产包、登记自己的设置字段、登记上面三个界面入口。没有快照或内容为空、或者开关被关掉时补丁为空,请求保持原样;它读不到完整会话正文,也不自行联网:远端资产一律经宿主提供的只读通道取件。

- 即使插件申请了读取会话的能力,也只能读到当前会话的可见内容,例如标题、消息正文、附件的名称与大小。
- 插件看不到 API Key,也看不到附件原件、请求快照与其他插件的数据。
- 插件数据只存在你的浏览器本地,单个插件上限 64KB;当前使用快照存在 IndexedDB 里,上限为 2 MB。清除浏览器站点数据时两者都会一并丢失,不要把它们当作可靠存储或密钥保管处。
- 卸载插件不会自动清除它留下的数据;面板会提示清理入口,需要时按提示清理。
- 作者签名是可选的:作者可以连同公钥一起发布签名,也可以不签。签名只覆盖 `plugin.js`,用来确认脚本来自该作者,插件元数据的完整性由插件合集校验。
- 只安装来自你信任的来源的插件。
